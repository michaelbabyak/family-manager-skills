# Weekly meal plan

Use when the household wants help answering "what are we eating this week" — without the agent deciding for them. This skill is opt-in: only run it if the owner asked for meal planning.

## The loop (owner picks, agent does the paperwork)

1. **Propose, don't decide.** Once a week, send 4–5 dinner ideas as a short chat message. Each idea gets one line: what it is, why it fits (quick night, uses what's on hand, kid-friendly), and roughly how long it takes.
2. **Learn the household's constraints first.** Dietary needs, dislikes, budget, which nights are busy (check the calendar — a late practice night means a 20-minute meal, not a project). Remember picks and rejections; don't propose the same rejected meal twice in a month.
3. **Owner picks and tweaks.** They choose, swap, or veto. One round of revision is normal.
4. **Grocery list from the picks.** Turn the chosen meals into a consolidated grocery list, grouped by store section. Cross off what the household already has before sending it. Hand the list to the owner's normal grocery flow — never order anything yourself.

## Rules

- Never auto-order groceries or meal kits. Proposals only; the owner approves every list.
- Kid-visible where it matters: if the kids see the plan (fridge list, kitchen paper), keep it fun, not preachy.
- Busy nights get easy meals. Check the family calendar before proposing.
- Keep the format the owner already uses if they have one (a spreadsheet, a note, a grocery app) — fit into it, don't replace it.
